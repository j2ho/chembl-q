# design/

Page designs that are not the published one.

`editorial.html` is the alternative treatment of the project page: hanging
margins instead of centred headings, no section rules, Newsreader and DM Mono.
It is kept here rather than in `docs/` because GitHub Pages serves everything
under `docs/`, and this file still describes **curated_v5** — every table and
figure in it was computed against that build. Publishing it alongside the
current page would put two different sets of numbers on the same site.

To switch designs, update this file's numbers and figures the way
`docs/index.html` was updated for v6, then swap the two files.
